# Project Statement

## Project Title
Simple Python Calculator

## 1. Problem Statement

Doing basic calculations again and again can take time, especially when we have to calculate different values. Sometimes it is also easy to make small calculation mistakes.

This project is made to create a simple calculator using Python. The user can enter two numbers and select an operator such as addition, subtraction, multiplication or division. The program then performs the selected calculation and displays the result.

The main purpose of this project is also to understand how Python concepts like input, conditions, operators and error handling can be used together to make a useful program.

## 2. Scope of the Project

The project is mainly focused on basic arithmetic calculations.

The calculator can:
- Take the first number from the user.
- Take an arithmetic operator from the user.
- Take the second number.
- Perform addition, subtraction, multiplication and division.
- Display the final result.
- Show a message when the user tries to divide by zero.
- Show an invalid operator message if the entered operator is not supported.

This is a basic calculator project, so it is mainly intended for simple calculations rather than advanced mathematical operations.

## 3. Target Users

This project can be used by:

- Students who want to perform basic calculations.
- Beginners learning Python programming.
- Users who need a small and simple calculator.
- Students who want to understand how conditional statements and operators work in Python.

## 4. High-Level Features

### 1. User Input
The program asks the user to enter two numbers and an operator.

### 2. Arithmetic Operations
It performs:
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)

### 3. Error Handling
The program checks for division by zero and displays an appropriate message instead of performing an invalid calculation.

### 4. Invalid Operator Handling
If the user enters an operator other than the supported operators, the program displays an invalid operator message.

### 5. Result Display
After performing the calculation, the result is displayed clearly to the user.

## 5. Technologies Used

- Python
- GitHub for version control

## 6. Project Objective

The objective of this project is to build a small and useful calculator while applying basic Python programming concepts such as variables, user input, if-elif-else statements, arithmetic operators and error handling.
